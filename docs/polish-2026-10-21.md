# Penyempurnaan alur latihan — 21 Oktober 2026

## Tujuan

Memudahkan siswa memeriksa jawaban sebelum mengirim latihan dan memahami hasil
tanpa merancukan pilihan **Benar/Salah** dengan penilaian jawaban.

Prioritas, review, dan pengujian ditangani agen **GPT-6.1 Sol high**. Worker
implementasi bekerja pada komponen latihan; perubahan lokal sebelumnya
dipertahankan. Antigravity CLI telah dicoba, tetapi berhenti sebelum mengubah kode
karena izin alat internal tidak dapat diminta dalam mode noninteraktif.

## Cakupan

- Tinjauan dari setiap soal dengan daftar soal, jawaban, serta akses untuk mengubah
  jawaban tertentu. Tinjauan tidak menampilkan kunci jawaban sebelum pengiriman.
- Konteks nama latihan dan label penilaian yang berbeda dari pilihan Benar/Salah
  pada halaman hasil.
- README mengikuti perintah yang tersedia dan menjelaskan batas provisioning
  administrator pada checkout ini.

Tidak ada perubahan kontrak database atau deployment. Attempt demo sementara
digunakan untuk pengujian tanpa mengubah konten guru maupun hasil demo bawaan.

## Pemeriksaan awal

- 19 tes / 152 assertions, lint, dan TypeScript lulus sebelum perubahan.
- Reviewer memeriksa penyimpanan pilihan **Salah**, navigasi ke beranda, dan
  pemulihan jawaban saat melanjutkan latihan melalui browser lokal.
- URL latihan pada tab awal tidak lagi tersedia. Pemeriksaan dilanjutkan dengan
  latihan demo yang tersedia; aturan akses tidak dilonggarkan.

## Pemeriksaan akhir

- **21 tes / 177 assertions lulus**, termasuk tes render baru untuk jawaban
  `true`, `false`, kosong, kontrol pending, nama latihan, dan label penilaian.
  Shell dialog dimock pada tes render; fokus dan portal diperiksa di browser.
- TypeScript, ESLint, dan `git diff --check` lulus.
- Browser memeriksa tinjauan dari soal awal, daftar jawaban, Ubah soal tertentu,
  fokus setelah dialog ditutup, pembatalan tinjauan, dan pergantian pilihan dengan
  tombol panah keyboard. Daftar tinjauan dapat digulir dan navigasi di belakang
  dialog tidak dapat dijangkau dengan Tab.
- Posisi fokus diperbaiki agar mengikuti kartu soal. Kontrol yang difokuskan dapat
  digulir sepenuhnya di atas navigasi bawah tanpa mengubah layout global.
- Klik ganda Kirim pada attempt sementara menghasilkan satu hasil **20/100**:
  satu jawaban benar, satu keliru, dan tiga belum dijawab. Database lokal
  mengonfirmasi hasil serta kedua pilihan `false` yang tersimpan.
- Ulangi latihan menghasilkan attempt baru dengan jawaban kosong dan tanpa hasil.
- Emit kontrak Prisma dan build produksi Next.js dengan `--webpack` lulus,
  termasuk kompilasi TypeScript dan 11/11 halaman statis. Secret pemeriksaan
  dibuat acak khusus proses build, tanpa mengubah `.env` atau sesi dev.
- Kedua attempt pengujian sementara telah dihapus dan query pembersihan
  mengonfirmasi tidak ada yang tersisa. Hasil demo bawaan tetap dipertahankan.
  Browser dikembalikan ke `/activities`; override viewport direset dan tidak ada
  peringatan/kesalahan console pada pemeriksaan akhir.
- `graphify update .` selesai melalui AST tanpa panggilan LLM: 9.604 node,
  13.813 edge, dan 568 komunitas. Ekstraksi berjalan berurutan karena pembatasan
  sandbox; 42 file tidak menghasilkan simbol yang didukung extractor.

## Cakupan visual dan batas pemeriksaan

Browser memeriksa tema gelap pada **390 × 844**, **768 × 1024**, dan
**1440 × 900** tanpa overflow horizontal pada alur yang diuji. Tema terang,
reduced motion, dan zoom 200% belum diuji pada pass ini; ini bukan audit visual
ulang seluruh aplikasi.

Perintah build default dengan Turbopack gagal karena lingkungan alat menolak
binding port (`EPERM`), termasuk setelah dicoba di luar sandbox. Build produksi
dengan Webpack lulus, tetapi hasil itu tidak membuktikan perintah build default
berhasil pada lingkungan ini. Tidak ada deployment atau migrasi database.
